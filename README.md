# 루미큐브 온라인

윤기 있는 상아색 도자기 타일, 녹청색 펠트 테이블, 월넛 받침과 황동색 포인트로 구성한 타일 게임(v1.5.1). 교제 문구와 시편 133:1은 차분하게 배치하고, 기본 조커는 십자가로 표시합니다.

친구들과 방 코드로 함께하는 루미큐브(2~6명). 서버는 이 컴퓨터에서 직접 돌립니다.
추가 설치 없이 Node만 있으면 됩니다 (외부 패키지 0개).

## 켜기

`루미큐브-서버-켜기.cmd` 를 더블 클릭 → 검은 창이 뜨고 브라우저가 열립니다.
**검은 창을 닫으면 서버가 꺼지고 진행 중인 게임도 사라집니다.**

## 친구가 들어오는 방법

| 상황 | 방법 |
|---|---|
| 같은 와이파이(집·교회 등) | 대기실의 **QR 코드를 폰 카메라로 찍기** (가장 쉬움). 또는 **초대 링크 복사**로 보낸 링크, 검은 창에 나오는 `http://192.168.x.x:3000` 주소. 처음에 Windows 방화벽 허용 창이 뜨면 **허용** |
| 멀리 있는 친구(인터넷) | 아래 둘 중 하나 |

- **QR 코드·초대 링크는 자동으로 '같은 와이파이 주소'로 만들어져요.** 이 컴퓨터에서 `localhost`로 열었어도
  친구 폰에서 열리는 `http://192.168.x.x:3000/?r=방코드`가 들어갑니다(서버의 `GET /api/info`가 이 컴퓨터의 와이파이 주소 목록을 알려 줌).
  인터넷 주소(터널·호스팅)로 열었으면 그 주소 그대로 들어갑니다.
- 컴퓨터에 네트워크 어댑터가 여러 개(VirtualBox·Hyper-V 등)면 QR 아래 **다른 주소**를 눌러 바꿔 볼 수 있어요.
- **QR을 누르면 'TV로 보기'** — 큰 방 코드와 큰 QR이 화면 가득. 목장 모임에서 프로젝터·TV에 띄워 두세요. 다시 누르면 닫혀요.
- QR 코드는 브라우저 안에서 직접 그려요(`public/qr.js`, 외부 라이브러리·인터넷 필요 없음). 교회 와이파이가 인터넷에 안 이어져 있어도 됩니다.
- **다시 들어오기**: 게임 중에 탭을 닫았거나 카톡 안 브라우저에서 다시 열어도, 같은 폰에서 초대 링크를 열면 내 자리·내 손패로 돌아와요.
  처음 화면에서도 **▶ 하던 게임으로 돌아가기** 버튼이 떠요. **방 나가기**를 누르면 이 기기에 남은 기록도 지워집니다.

### 인터넷으로 열기

1. **임시로 열기 (가장 쉬움)** — Cloudflare Tunnel(`cloudflared`)을 받아서
   서버를 켠 상태로 `cloudflared tunnel --url http://localhost:3000` 실행 →
   나오는 `https://….trycloudflare.com` 주소를 친구에게 보내기. 계정 필요 없음, 컴퓨터가 켜져 있는 동안만 동작.
2. **항상 켜 두기** — Render, Railway, Fly.io 같은 Node 호스팅에 이 폴더를 올리고 시작 명령을 `node server.js`로 지정.
   (포트는 호스팅이 주는 `PORT` 환경변수를 자동으로 씀)

> Netlify는 정적 파일만 올리는 곳이라 이 서버는 돌아가지 않습니다.

## 게임 방법

- 방장이 **새 방 만들기** → 4글자 방 코드나 초대 링크를 친구에게 보냄 → 2명 이상 모이면 **게임 시작**
- 대기실에서 **🤖 쉬움 봇 추가** / **🤖 어려움 봇 추가**로 컴퓨터 상대를 넣습니다(✕로 빼기). 혼자서 봇과 하거나, 친구 + 봇을 섞어 6명까지.
  방장은 봇 옆의 **쉬움/어려움** 표시를 눌러 난이도를 바꿀 수 있어요. 봇은 놓기 전에 1초쯤 놓는 모습을 보여 줍니다.
  - **쉬움**: 한 턴에 묶음 하나만 내고, 조커는 안 쓰고, 테이블에 붙이기도 가끔만 해요. 아이들·처음 하는 분용.
  - **어려움**: 테이블의 모든 묶음을 통째로 다시 짜서 손패를 가장 많이(높은 숫자부터) 내려놓는 방법을 계산해요. 조커는 꼭 필요할 때만 써요.
    시험 대국에서 쉬움 상대로 30판 중 29~30판을 이겼어요.
- **혼자 연습하기**: 쉬운 컴퓨터 1명이 있는 **연습 준비** 대기실로 들어갑니다(기본 시간 제한 없음). 이름을 안 써도 돼요. 쉬움/어려움 봇을 최대 5명까지 넣고, 난이도 변경·삭제 후 **게임 시작**을 누르세요.
- **📖 규칙 한눈에**: 처음 화면 아래, 게임 중 ⋯ 메뉴 맨 위(넓은 화면은 위쪽 **?**). 진짜 타일 그림으로 그룹·런·조커·첫 등록을 보여 줘요.
  처음 하는 분에게는 게임 중에 짧은 안내 말풍선이 기기마다 한 번씩만 떠요(누르면 닫힘, **다시 보지 않기**).
- 손패 타일을 **눌러 고르고**(여러 개 가능) → 테이블의 묶음이나 **새 묶음 만들기**를 누르면 옮겨집니다. 컴퓨터에선 끌어다 놓기도 되고,
  키보드만으로도 할 수 있어요(Tab으로 타일·묶음 이동 → Enter/Space, Ctrl+Z 한 수 되돌리기). 테이블에 놓았던 내 타일은 손패의 **↩** 자리를 눌러 되돌려요.
- 폰을 가로로 들면 테이블이 넓어지도록 타일·위쪽 막대가 조금 작아지고, 안내 말풍선은 떠 있다가 7초 뒤 저절로 닫혀요.
  아이폰처럼 진동이 없는 기기에서는 소리 단추가 **소리 켜짐 ↔ 꺼짐** 두 가지만 바뀌어요.
- 만드는 중인 묶음은 무엇이 모자란지 한 줄로 알려 줘요. 다 맞으면 **완료**, 낼 게 없으면 **뽑기**. **↶ 한 수**는 한 수씩 되돌리기, **처음**은 이번 턴 처음 상태로.
- 첫 등록은 내 타일만으로 30점 이상, 그 전엔 테이블을 못 바꿈.
- 다른 사람 차례에는 그 사람이 타일을 옮기는 모습이 실시간으로 보입니다.
- **채팅**: 대기실에선 카드 아래 대화 상자, 게임 중엔 위쪽 💬 버튼(안 읽은 수 표시)으로 엽니다. 창을 닫아 둬도 새 메시지가 잠깐 말풍선으로 떠요.
  자주 쓰는 말(아멘 🙏, 👍 좋아요, 할렐루야 🙌 …)은 한 번 눌러 보내기. 봇도 인사하고 좋은 수에 박수를 쳐 줘요. 한 메시지 100자, 도배 방지(10초에 5개).
- **⋯ 메뉴 → 내 화면 설정** (이 기기에만 저장, 다른 사람 화면은 그대로)
  - **색 구분 기호**(기본 켬): 빨강 ● 파랑 ▲ 주황 ■ 검정 ◆ 작은 모양을 타일 왼쪽 위에 — 빨강·주황이 헷갈려도 모양으로 구분.
  - **큰 타일**: 타일과 글씨를 약 1.25배로 (어르신·작은 폰).
  - **효과 줄이기**: 움직이는 효과를 끔(색과 소리는 그대로). 폰에서 '동작 줄이기'를 켜 두었으면 처음부터 켜져 있어요.
  - **조커 모양**: 십자가(기본) / 별 / 비둘기 — 진짜 타일 미리보기 중에서 고름. 그림 문자 대신 그림(SVG)이라 어느 폰에서나 똑같이 보여요. v1.4.1 업데이트 후에는 기존 기기도 십자가로 시작하고, 이후 선택은 기기에 저장합니다.
    내 화면에만 적용되고 서버로 보내지 않아요. 글에서는 늘 '조커'라고 부르고, 감점은 '조커 −30'으로만 적어요.
- **오늘의 시상식**: 판이 끝나면 점수가 올라가며 보이고, 이어서 한 사람에 하나씩 상아색 카드에 상이 켜져요
  (승리 · 재건축왕 · 한 방의 손 · 첫 열매 · 조커의 달인 · 부활의 손 · 끈기상 · 함께해서 기뻐요). 상은 점수와 상관없는 명예상이에요.
  카드를 누르면 기다리지 않고 한 번에 다 보여요. 아래에 시편 133:1과 '오늘 n판' 누적 점수·★(이긴 판)가 나와요.
- **📋 결과 공유**: 폰에서는 공유 창(카카오톡 단톡방 등)이, 컴퓨터에서는 복사가 돼요. 6줄 이하 · 주소와 손패는 넣지 않아요.
- 방장은 대기실에서 턴 제한 시간(없음/60초~3분)을 정할 수 있어요. 시간이 지나면 자동으로 1장 뽑고 넘어갑니다.
- 타이머가 없을 때 차례인 사람이 45초 넘게 연결이 끊기면 자동으로 뽑고 넘어갑니다. 새로고침해도 같은 탭이면 다시 이어서 할 수 있어요.
- 누가 손패를 다 내면 승리. 진 사람은 남은 타일 합(조커 30)만큼 감점, 승자는 그만큼 가산. 더미가 떨어지고 모두 패스하면 남은 합이 가장 적은 사람이 승리.

## 한국어 / English

- 처음 화면·대기실 아래, 게임 중 ⋯ 메뉴 맨 위의 **한국어 | English** 로 언제든 바꿔요. 새로고침 없이 바로 바뀌고, 이 기기에 기억돼요.
- 처음엔 폰·컴퓨터 언어를 따라가요(한국어 기기는 한국어, 그 밖은 영어).
- **사람마다 따로** 정해요. 한 방에서 한국어로 하는 사람과 영어로 하는 사람이 같이 해도, 진행 기록·오류 안내·규칙 설명·시상식·봇 인사는
  각자 자기 말로 보여요(서버는 문장 대신 '무슨 일인지'만 보내고 화면이 각자 말로 바꿈). 사람이 쓴 채팅은 번역하지 않아요.
- 영어 성경 구절은 시편 133:1 KJV(저작권 없음)를 써요.

## 컴퓨터 상대 자유롭게 구성하기 (v1.2.0)

- **연습 준비**: 쉬운 봇 1명을 기본으로 넣고 기다립니다. 바로 시작하지 않습니다. 1~5명의 봇을 쉬움/어려움으로 섞고, 각 봇의 난이도 표시를 눌러 바꾸거나 ✕로 뺀 뒤 시작합니다.
- **친구와 하기 · 방 만들기**: 방장이 친구와 봇을 섞어 최대 6명으로 구성합니다. 친구는 봇 구성과 난이도 변경을 실시간으로 봅니다.
- 빈자리 수, 가득 찬 상태, 방장 권한을 안내합니다. 상대 설정 요청이 진행되는 동안 추가·삭제·난이도·시작 요청이 겹치지 않게 막습니다.
- 연습 화면에서는 상대 설정을 먼저 보여 주고 초대 QR은 **친구도 초대하기 · QR 보기**로 펼칩니다. 새로고침해도 연습 준비 모드가 유지됩니다.
- 상대 변경은 게임 시작 전에 가능합니다. 진행 중인 게임의 참가자나 난이도는 바꾸지 않습니다.
- 검증: `test.js` 69개 통과 및 `qa/bot-setup.cjs`의 Chrome/WebKit × 320/390/844/1280px × 한국어/영어 × 연습/친구(32개 조합, 390/844px는 `--extra`). 실제 두 브라우저 세션으로 방장/친구 동기화, 추가·삭제·난이도, 최대 6명, 중복 요청, 새로고침, 게임 시작을 검사합니다.

## 밝은 테이블 디자인 (v1.3.0 · 2026-10-11)

- 홈·대기실·게임판·채팅·설정·규칙·결과를 오프화이트, 민트, 블루로 통일했습니다. 장식 테두리와 명조체를 덜고 주요 행동은 파란색으로 표시합니다.
- PC 홈에는 타일 일러스트와 입장 카드를 나란히, 폰에는 입장 카드를 중심으로 배치합니다. 친구와 하기·혼자 연습하기 버튼에는 간단한 선 아이콘과 설명을 붙였습니다.
- 넓은 PC 연습 대기실은 상대 설정과 채팅을 나란히 배치하고, 6명 참가자는 2열로 정리합니다. 게임 중에는 기존 PC 3열·폰 2열 자리표를 유지합니다.
- 외부 웹폰트 요청을 제거하고 시스템 글꼴을 사용합니다. 로고와 홈 일러스트도 로컬 SVG입니다. 기본 SVG 조커와 선택·착지·확정 효과는 새 색상에 맞췄습니다.
- 기본 색상·표현은 `public/modern.css`에 모았습니다. 홈 그림은 `public/table-scene.svg`, 브라우저 아이콘은 `public/brand.svg`입니다. v1.4 타일 재질과 효과는 그 뒤에 불러오는 `public/table-feel.css`가 담당합니다.
- Chrome/WebKit의 320~1920px·한국어/영어에서 조작·스크롤·연결 안내·채팅 초안 등을 검사했습니다. `qa/modern.cjs`는 6인 대기실과 게임, 설정, 규칙, 채팅, 6인 결과의 화면을 검사합니다. 결과 화면과 혼잡한 손패는 화면 검사용 상태입니다.
- 터치 에뮬레이션에서 선택·스크롤 유지·언어 전환·채팅·가로 회전을 검사합니다. 실물 휴대폰의 가상 키보드·노치·스피커 음질은 별도 확인이 필요합니다.

## 타일 질감·손맛·자연스러운 문구 (v1.4.0 · 2026-10-11)

- 게임 타일에 상아색 레진 표면, 작은 표면 무늬, 빛을 받는 모서리와 3px 두께를 표현했습니다. 숫자·색 구분 기호·조커의 대체 숫자는 그대로 읽을 수 있습니다. 표면 무늬는 1KB 미만의 로컬 SVG입니다.
- v1.4.2에서는 숫자의 흰색·짙은색 양각 그림자를 제거했습니다. 작은 크기에서 숫자 가장자리가 흰 점이나 얼룩처럼 보이던 문제를 수정했고, 타일 표면·테두리·두께 효과는 유지합니다.
- `qa/tile-audit.cjs`와 `--extra`로 숫자 156개(4색 × 1~13 × 3벌)와 조커 4개, 선택·새 타일·이동 복사본·확정 등 9가지 상태를 점검했습니다. Chrome/WebKit, 320/390/1280px, 픽셀 밀도 1/2/3, 기본·큰 타일의 20개 조합을 검사하며 전체 목록과 원인 비교 화면은 로컬 `qa/tile-audit`에 저장합니다. 실물 기기 대신 브라우저 에뮬레이션을 사용합니다.
- 타일은 210~280ms 동안 새 자리로 이동한 뒤 145ms의 작은 착지 반동을 보입니다. 손패에서 테이블로 이동하는 타일을 먼저 연출하고, 최대 28개 복사본과 착지 링 4개로 제한합니다.
- 짧은 마찰음 뒤 착지 순간에 단단한 접촉음이 나옵니다. 완성음은 실제 이동 완료를 기다린 뒤 이어집니다. 이동을 취소하거나 화면을 다시 그렸다면 대기 중인 소리와 효과도 취소합니다.
- 런·그룹이 처음 완성되면 짧은 확인 문구와 빛·작은 입자를 보여 줍니다. 규칙에 맞지 않는 묶음에는 완성 효과가 없습니다. 선택이나 언어 변경으로 다시 그려도 보상 효과를 반복하지 않습니다.
- 서버가 차례를 확정하면 묶음별로 타일이 살짝 반응합니다. 여러 장을 낸 수는 강하게, 새 조커가 포함된 묶음은 보라색으로 구분합니다. 첫 등록과 승리 연출도 기존 흐름과 연결됩니다.
- 서버가 본인의 미리보기를 돌려줄 때, 시각적으로 같은 상태이면 게임판을 다시 그리지 않습니다. 150ms 미리보기 응답이 280ms 타일 이동을 끊던 문제를 해결했습니다. 참가자 연결 상태·손패·차례처럼 실제 값이 달라지면 갱신합니다.
- 메뉴의 **효과음 크기**는 기기에 저장됩니다. 소리를 끄면 재생 중인 효과음도 부드럽게 줄입니다. **효과 줄이기**에서는 이동·반동·입자를 생략하고 접촉음과 확인 문구는 바로 표시합니다. 진동은 지원 기기에서만 동작합니다.
- 한국어·영어 문구 77개를 다듬었습니다. 예: “한 방의 손” → “시원한 한 수”, “First Fruits” → “First to Meld”, “A lot of together” → “Make your move. Share a laugh.”. 더미가 소진됐을 때의 승리 설명도 남은 **타일 점수**를 기준으로 표시합니다. 성경 인용문은 유지했습니다.
- 검증: `test.js` 69개, `qa/feel.cjs` Chrome/WebKit·PC/폰·한영 8개 조합, `qa/craft.cjs` 28개 화면/언어 조합, 이동·터치 검사. 실제 서버에 합법적인 테스트 배치를 구성한 `qa/feel-preview.cjs`에서 Chrome/WebKit 각각 미리보기 수신, UI로 7장 놓기, 서버 확정, 조커·큰 수 효과, 160개 타일 보존과 연결 상태 갱신을 검사했습니다.
- WebAudio를 오프라인으로 렌더링해 음량 0의 무음, 음량 변화, 파형의 과도한 잘림 여부도 확인합니다. 실제 스피커의 음색·음량과 휴대폰 진동 감각은 실기기 확인이 필요합니다.

## 큰 수를 위한 말풍선 연출 (v1.5.1 · 2026-10-11)

- “와! 한 번에 7장”을 굵은 입체 글자와 비스듬한 말풍선으로 강조합니다. 문구가 미끄러져 들어와 탄력 있게 멈추고, 붉은 숫자가 한 박자 늦게 내려앉습니다. 황동색 테두리·빛의 획·8개의 짧은 광선은 테이블 안에서만 나타납니다.
- 6장 이상 놓기, 기존 묶음 3개 이상 재배치, 첫 등록, 마지막 타일 놓기에 각각 문구를 표시합니다. 큰 수와 첫 등록이 겹치면 큰 수를 제목으로, 등록 점수를 아래에 표시합니다. 보통 수에는 작은 장수 안내만 나옵니다.
- 큰 수의 말풍선은 약 1.25~1.5초 안에 걷히고, 승리 문구는 결과창 직전에 잠깐 표시합니다. 누르거나 키를 누르면 즉시 건너뛰며, 그 입력으로 메뉴 열기 등 원래 동작도 실행됩니다. 화면 회전·언어 변경·백그라운드 전환·동작 줄이기 변경 시 기존 연출을 정리합니다. 짧은 가로 화면에는 작은 한 줄 말풍선을 사용합니다.
- 한국어·영어 제목에 로컬 Black Han Sans 글꼴을 사용합니다(필요한 글자만 담은 WOFF2 13.6KB). Google Fonts 연결 없이 동작하고, 글꼴이 차단되면 시스템 글꼴로 표시합니다. 사람 이름과 보조 설명에는 기본 UI 글꼴을 씁니다. [SIL OFL 1.1](https://raw.githubusercontent.com/google/fonts/main/ofl/blackhansans/OFL.txt) 라이선스를 `public/reveal-display-OFL.txt`에 포함합니다. 새 한국어 제목을 추가할 때는 `qa/fetch-reveal-font.cjs`의 글자 목록도 갱신해야 합니다.
- ‘효과 줄이기’와 기기의 동작 줄이기에서는 확대·이동·광선을 끄고 정적인 말풍선만 표시합니다. 숫자 타일에는 양각 글자 그림자를 추가하지 않습니다.
- `qa/reveal.cjs`는 Chrome/WebKit의 PC·폰·짧은 가로 화면 40개 한영 배치(보통/큰 타일), 네 종류의 문구, 입력 통과, 설정 변경과 정리를 검사합니다. `qa/feel-preview.cjs --cinematic`은 실제 6인 서버에서 UI로 7장을 놓아 API·실시간 상태 수신·160개 타일 보존과 연출을 함께 확인합니다. 화면 배치 검사는 별도의 고정 테스트 상태를 사용합니다. 영상·화면·검사 결과는 로컬 `qa/reveal`에 있으며 배포 파일에는 포함하지 않습니다.
- 작혼의 굵은 화료 글자와 짧은 등장 동작을 참고했습니다. 말풍선·모션·광선은 이 게임의 도자기 테이블에 맞게 직접 제작했습니다.

## 도자기 테이블 · 아날로그 손맛 (v1.5.0 · 2026-10-11)

- 홈·대기실·게임·설정·규칙·채팅·결과를 따뜻한 아이보리, 녹청색, 황동색으로 맞췄습니다. 테이블은 빛이 은은하게 퍼지는 펠트, 손패 받침은 안쪽 홈과 나뭇결이 있는 월넛으로 구분합니다. 홈의 테이블 그림과 아이콘도 같은 재질과 색으로 새로 그렸습니다.
- 도자기 타일은 유약 반사, 둥근 모서리, 4px 옆면과 접촉 그림자를 표현합니다. 반사광은 글자 뒤의 표면에 그립니다. v1.4.2에서 제거한 숫자의 양각 그림자는 되살리지 않으며, 기본 십자가 조커와 색 구분 기호를 유지합니다.
- 선택하면 타일이 살짝 기울어 올라오고 황동색 테두리가 생깁니다. 타일을 놓으면 짧은 접촉음과 작은 반동, 조합을 완성하면 확인 문구와 은은한 빛이 이어집니다. 큰 수·조커 확정 효과도 테이블의 금빛 계열로 맞췄습니다.
- 본인이 뽑은 타일은 상단 더미에서 손패로 390ms 동안 들어와 안착하며, 나무 받침에 닿는 낮은 소리가 납니다. 서버의 실제 지급 상태를 받은 뒤에만 시작합니다. HTTP 응답이 먼저 오거나 나중에 와도 연출을 중복하지 않고, 응답 완료가 이미 시작한 이동을 끊지 않습니다. 패스와 실패한 요청에는 뽑기 소리가 없습니다.
- 손패가 길어 새 타일이 가려졌다면 그 자리로 스크롤해 보여 줍니다. 효과 줄이기에서는 이동을 생략하고 접촉음을 바로 냅니다. 다음 조작·스크롤·화면 회전·탭 숨김에서 복사본과 대기 중인 접촉음을 취소하고 실제 타일을 복원합니다. 초기 입장·새로고침·언어 전환에는 뽑기 효과를 반복하지 않습니다.
- 선택·정렬·뽑기·착지 소리를 마찰음과 낮은 접촉음 중심으로 조정했습니다. 조합 완성·첫 등록·승리의 화음, 음량 설정, 무음·진동 지원은 유지합니다. 소리는 외부 파일 없이 WebAudio로 만듭니다.
- 작은 폰의 6인 자리표와 더미·채팅·메뉴가 겹치지 않게 헤더를 조정했습니다. 높이 360px 이하의 짧은 가로 화면은 받침을 한 줄 높이의 스크롤 영역으로 줄여 게임판과 완료 버튼을 확보합니다. 모바일 터치, 키보드, 큰 타일, 한국어/영어, 기본 106개·확장 160개 게임 구성은 유지합니다.
- 검사 스크립트: `qa/atelier-draw.cjs`는 실제 서버/UI/SSE로 뽑기 응답 순서·단일 소리·타일 보존·취소·큰 손패·패스·실패·새로고침을 검사합니다. `qa/atelier-layout.cjs`는 긴 이름의 6인 자리표·타이머·큰 타일·짧은 가로 화면·고대비 모드를 확인합니다. `qa/modern.cjs --atelier`와 `qa/feel-preview.cjs --atelier`는 새 화면과 실제 합법 수의 미리보기를 로컬 `qa/atelier`에 저장합니다. QA 파일은 배포용 폴더에 포함하지 않습니다.
- 검증 결과: 기본 검사 69개, 전체 화면 16개 조합, UX 28개 조합, 6인 레이아웃 40개 조합(각각 선택 상태도 확인), 타일 전수 검사 20개 조합, 실제 뽑기 4개 조합, 착지·완성·음량 8개 조합이 통과했습니다. Chrome/WebKit에서 실제 6인 서버의 뽑기·7장 놓기·조커 확정·160개 타일 보존도 확인했습니다. 새 마찰·접촉음을 포함한 10개 음량/소리 샘플을 오프라인 렌더링해 무음·음량 변화·클리핑을 검사했습니다.
- Chrome/WebKit 브라우저 에뮬레이션으로 검사합니다. 실물 휴대폰의 가상 키보드·노치·스피커 음색·진동 감각은 별도 확인이 필요합니다.

## 파일

- `server.js` — 서버 (방, 차례, 규칙 최종 판정, 실시간 전송). 손패는 본인에게만 보내므로 개발자도구로 남의 패를 볼 수 없음
- `bot.js` — 컴퓨터 상대의 수 계산 (쉬움 / 어려움). `bot-worker.js`가 별도 스레드에서 돌려서 봇이 생각하는 동안에도 서버가 멈추지 않음
- `public/rules.js` — 규칙 판정 (서버와 브라우저가 같이 씀)
- `public/index.html`, `app.js`, `style.css` — 화면
- `public/modern.css` — 화면 배치와 디자인의 기본 구조
- `public/atelier.css`, `felt-weave.svg`, `wood-grain.svg`, `table-scene.svg`, `brand.svg` — v1.5 도자기·펠트·월넛 테이블과 로컬 벡터 그림
- `public/table-feel.css`, `table-feel.js`, `tile-grain.svg` — v1.4 타일 재질·착지·완성 효과와 음량 조절 UI
- `public/flow.js`, `flow.css` — 대기실 QR·TV로 보기, 오늘의 시상식·결과 공유, 규칙 한눈에, 처음 안내, 혼자 연습, 내 화면 설정 모양
- `public/i18n.js` — 한국어·영어 사전과 말 바꾸기
- `public/sfx.js` — 소리·진동 (파일 없이 브라우저에서 직접 만든 종소리, 한 음계라 겹쳐도 어울림)
- `public/qr.js` — QR 코드 그리기 (외부 라이브러리 없이, 오류 정정 M, 버전 1~10)
- 서버가 보내는 상태에는 판마다의 기록(`awards` 시상식, `history` 오늘 판 기록)과 사람마다 `offFor`(연결 끊긴 초)·`graceLeft`(자동 진행까지 남은 초)가 들어 있어요
- `test.js` — 테스트: `node test.js`

## 이전 디자인 개선 (2026-10-10 · v1.3에서 색상·표현 변경)
- PC 첫 화면: 소개와 입장 카드를 나란히 배치. 폰에서는 입장 중심의 단일 카드.
- 청남색 게임판, 슬레이트 받침, 상아색 타일로 시각적 계층 정리.
- 새로운 소개 문구는 한국어/영어 전환 지원.
- 디자인은 public/polish.css에 분리하여 조정 가능.
- 검증: test.js 62개 통과. qa/compat.cjs로 Chrome 6개 크기(360,390,768,844,1280,1920px), 한영 홈과 연습 게임 검사.
- 이후 v1.2 검증에서는 WebKit도 실행했습니다. 실제 휴대폰의 키보드·노치·진동·스피커 음질은 실기기 확인이 필요합니다.

## 타일 이동 효과 (2026-10-10)
- 손패 정렬 시 타일이 새 자리로 이동하며, 놓기·되돌리기·상대 재배치도 위치 변화를 보여 줍니다.
- 같은 영역 이동 220ms, 영역 간 이동 280ms. 최대 28개 시각 복사본만 사용하며 게임 상태와 입력은 기다리지 않습니다.
- 효과 줄이기 / 기기 동작 줄이기에서는 이동을 생략합니다.
- 연속 조작, 화면 크기 변경, 탭 숨김에서 효과를 정리하며 완료 이벤트가 지연돼도 시간 제한으로 복원합니다.
- qa/motion.cjs: PC·폰 크기에서 정렬, 놓기, 정리, 효과 줄이기 검사.

## UX 정교화 (2026-10-10)
- 선택 상태를 손패 위에 표시: 선택 개수, 새 묶음에 놓기, 손패로 돌리기, 선택 해제. Esc로도 선택 해제.
- 4명 참가자 이름표는 좁은 폰에서 2열로 배치. 긴 이름은 말줄임하고 타일 수는 유지.
- 손패 높이를 제한하고 내부 스크롤 적용. 손패·테이블·긴 묶음의 스크롤 위치는 타일 선택·언어 전환 후에도 보존.
- 연결 중/재연결/오프라인을 구분해 안내. 연결이 불안정하면 서버 확정 버튼을 막고 로컬 작업은 보존(실제 차례가 바뀌면 서버 상태를 따름).
- 전송 중 중복 뽑기·완료 요청 방지, 제출한 타일 배열 복사, 네트워크 요청 12초 제한과 번역된 오류 메시지.
- 채팅 중복 제출 방지. 전송 중 다음 메시지를 작성했다면 새 문장을 지우지 않음.
- PC 키보드: 방향키로 타일 이동, Home/End로 처음·끝, Enter/Space로 선택. 새 묶음에 놓은 뒤 초점이 타일을 따라감.
- 정렬 단추는 실제 정렬 상태를 표시. 규칙·결과 창의 Tab 초점이 뒤쪽 화면으로 빠지지 않음.
- 검사: 기존 62개 통과. Chrome·WebKit 각각 7개 화면×한국어/영어(총 28개 조합), 손패 40개·4명·긴 묶음·큰 타일·연결 상태·중복 제출·채팅 초안 검사.
- iPhone 13 터치 에뮬레이션: Chrome/WebKit에서 선택 후 스크롤 보존·언어 전환·채팅·가로 회전 통과. 별도 키보드 및 타일 효과 회귀 검사 통과.
- 실물 Galaxy/iPhone, 실제 운영 서버의 인터넷 지연, 운영체제 가상 키보드는 별도 확인 필요.
- 테스트 스크린샷은 qa/craft-chrome, qa/craft-webkit에 있음(혼잡한 손패·긴 묶음은 검사 상태로 구성).
