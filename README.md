## v2.2.1 · 판과 내 손패를 함께 보기 (2026-10-27)

판 전체 보기 아래에 **내 손패**를 고정 표시합니다. 판을 확대하거나 다른 사람 차례를 보고 있을 때에도 내 타일을 함께 비교할 수 있습니다. 원래 손패의 정렬 순서·선택 표시를 유지하고, 이번 턴에 테이블에 옮긴 타일은 중복 표시하지 않습니다. 많은 손패는 받침 안에서 따로 스크롤하며 짧은 가로 화면에서는 한 줄로 살펴봅니다. 보기 화면을 닫거나 방을 떠나면 손패 복사본을 정리합니다. 본인에게 전달된 손패만 사용하며 상대 손패는 읽거나 표시하지 않습니다.

## v2.2 · 판 전체 보기 · 직접 시간 설정 · 손끝 피드백 (2026-10-27)

- 게임의 **판 전체 보기**에서 손패에 가리지 않고 테이블을 확인합니다. **한눈에 보기 / 크게 보기 / − / +**로 확대하고 스크롤합니다. 내 차례에 만들던 조합도 보이며, 보기 전용이어서 선택·수순을 바꾸지 않습니다. 다른 사람의 비공개 손패는 표시하지 않습니다. 차례와 제한 시간은 계속 진행됩니다. 키보드 초점·Escape·작은 세로 화면·가로 화면·한국어/영어를 지원합니다.
- 방장은 대기실의 **차례당 제한 시간 → 직접 설정 → 초 입력 → 적용**으로 5~1800초 사이의 정수를 설정합니다. 기존 선택지와 제한 없음도 유지합니다. 참가자가 들어오거나 채팅해도 아직 적용하지 않은 입력을 지우지 않습니다. 게임 중에는 시간을 바꿀 수 없습니다.
- 채팅에 **스겜 / GG** 원터치 전송을 추가했습니다. 영어에서는 **Quick game? / GG**로 표시합니다. 기존 채팅 속도 제한과 모바일 말풍선을 사용합니다.
- 도자기 면의 윤기·모서리·접촉 그림자를 다듬고, 숫자 잉크는 깨끗하게 유지합니다. 자체 합성한 짧은 달칵음에 중역의 도자기 울림을 더했습니다. 타일 착지와 조합 완성에 짧은 피드백을 맞추고 전체 화면 흔들림은 사용하지 않습니다.
- **⋯ 메뉴 → 손끝 진동**에서 소리와 별도로 진동을 켜고 끄거나 테스트합니다. 타일 집기·착지·조합 완성에 다른 길이의 진동을 사용합니다. 설정은 기기에 저장됩니다. 전체 끔은 진동도 멈춥니다. 표준 Vibration API를 지원하는 브라우저에서 동작하며 iPhone Safari는 지원하지 않습니다. 실제 모터의 세기는 제어하지 않습니다.
- 다음 개선 후보는 공개된 수만 보여 주는 턴 리플레이, 복잡한 판에서 바뀐 묶음 강조, 타일 재질별 사운드 선택입니다. 아직 구현되지 않은 기능입니다. 현재 규칙·덱의 무작위성·봇 판단은 유지합니다.

참고: [Tetris Effect 작곡가의 소리·시각 연출 조율 과정](https://blog.playstation.com/2020/05/28/inside-the-creation-of-tetris-effects-original-soundtrack-out-today/), [MDN Vibration API](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/vibrate). 게임 소재를 복제하지 않고 자체 그래픽·합성음을 사용합니다.

## v2.1.1 · 쉬움 봇의 실수

쉬움에만 초보자처럼 수를 놓치는 판단을 추가했습니다. 타일 셔플·분배·뽑기와 중간/어려움의 계산은 유지합니다.

- 새 묶음을 찾은 뒤 일부를 놓치거나, 붙일 수 있는 타일을 못 보고 뽑기도 합니다. 긴 묶음에서 한 장을 덜 내는 선택도 할 수 있습니다. 판정 자체를 틀리거나 불법 묶음을 확정하지는 않습니다.
- 쉬움의 제한된 탐색이 찾아낸 **첫 등록과 즉시 승리 수**에는 추가 실수를 적용하지 않습니다. 복잡한 재배치까지 찾아주는 것은 아닙니다. 대타 봇도 쉬움과 같은 전략을 사용합니다.
- 기회별 설정은 묶음 누락 18%, 붙이기 누락 28%, 긴 묶음의 짧은 대안 검토 25%입니다. 기회가 겹치거나 나중에 다른 수로 연결되므로 전체 차례의 실수율과 같지는 않습니다. 4,000회 고정 난수 검사에서 묶음 누락 17.5%, 붙이기 누락 28.1%를 확인했습니다.
- 실수 난수는 봇의 수 선택에만 사용합니다. 서버의 암호학적 셔플·분배·순차 뽑기 경로는 v2.1과 파일 내용까지 같습니다. 공정성 재현 검사도 유지합니다.

## v2.1 · 타일 공정성 점검과 3단계 봇

운영 v2.0 소스를 대조한 결과, 난이도에 따라 사람의 타일 분배·뽑기를 보정하는 경로는 없었습니다. 기존/수정 서버를 같은 난수 조건으로 40,000회 재현해 시작 손패·선공·전체 뽑기 순서가 같음을 확인했습니다. 자세한 코드 경로와 검사 범위는 [타일 공정성 점검](타일-공정성-점검.md)에 기록했습니다.

- **쉬움:** 단순 손패 조합들을 순서대로 고르고 기존 묶음에 붙입니다. 후보를 되짚어 비교하거나 테이블을 재배치하지 않습니다. 조커도 단순 조합에 쓸 수 있으며 확률적으로 붙이기를 건너뛰거나 한 묶음만 내던 제한은 제거했습니다.
- **중간:** 여러 손패 묶음 비교, 붙이기, 런 쪼개기, 기존 묶음의 한 장을 활용하는 부분 재배치입니다.
- **어려움:** 중간 전략에 공개 테이블 전체를 다시 구성하는 탐색을 더합니다. 시간·상태 수 한도 안에서 계산하며 전역 최적해를 보장하지는 않습니다.
- 연습·친구 대기실에서 세 난이도를 추가할 수 있습니다. 봇 옆 난이도를 누르면 쉬움 → 중간 → 어려움 순으로 바뀝니다. 방장 권한·6인 제한·대타 봇의 쉬움 난이도는 유지합니다.
- 봇은 자기 손패와 공개 테이블만 받습니다. 남은 더미나 다른 참가자의 비공개 손패는 받지 않습니다. 게임은 공통 셔플 한 번과 순차 뽑기를 사용합니다.

## v2.0 · 잠금 화면 알림과 기기 변경 복귀

- **⋯ 메뉴 → 내 차례 알림 → 푸시 알림 켜기**를 직접 눌러 권한을 허용합니다. 서버가 암호화한 Web Push를 보내므로 다른 앱을 보거나 화면이 잠겨 있어도 시스템 알림을 받을 수 있습니다. 화면을 보고 있는 차례는 수신 확인으로 중복 푸시를 억제합니다. **알림 테스트**로 이 기기의 수신을 확인하세요. 화면 배너·세 음 알림음·소리 설정도 유지합니다. 시스템 알림 소리는 휴대폰의 알림·무음·집중 모드 설정을 따릅니다.
- 아이폰·아이패드는 iOS/iPadOS 16.4 이상에서 Safari의 **공유 → 홈 화면에 추가** 후 설치한 앱에서 알림을 켭니다. Safari와 설치 앱의 저장 공간이 다를 수 있으므로 먼저 개인 복귀 코드를 복사해 두고 설치 앱에서 입력하세요. Android와 PC는 지원 브라우저의 설치 메뉴 또는 게임 메뉴의 설치 버튼을 사용합니다. 사용자가 누르기 전에는 권한을 요청하지 않습니다.
- 같은 기기·브라우저에서는 **4자리 방 코드**로 원래 자리에 돌아옵니다. 참가 정보를 IndexedDB에도 별도로 보관해 기본 저장소가 유실된 경우 복귀를 돕습니다. 모든 브라우저 데이터를 삭제하면 이 사본도 사라집니다.
- 다른 기기에서는 게임의 **⋯ 메뉴 → 내 자리 → 개인 복귀 코드**에 있는 **12자리 코드**를 첫 화면 참가 칸에 입력합니다. 닉네임 없이 같은 자리·손패·점수로 이어집니다. 개인 코드는 기본 가림 처리하며 복사·보기 버튼을 제공합니다. 이 코드를 가진 사람은 내 자리를 이어받을 수 있으므로 다른 사람에게 보내지 마세요. 새 기기로 복귀하면 이전 접속을 종료하고 기존 푸시 등록도 정리하므로 새 기기에서 알림을 다시 켭니다.
- 인터넷 끊김·앱 종료는 45초간 기다린 뒤 쉬움 봇이 대타를 맡습니다. 돌아오면 봇의 미확정 수를 취소하고 이미 둔 수를 유지합니다. 직접 나가면 즉시 대타로 바뀝니다. 방은 모두 떠난 뒤 30분간 보존하며 서버 재시작·절전·재배포로 사라진 방은 복구하지 못합니다.
- 방장 연결이 끊기면 다른 접속자가 대기실이나 게임 메뉴의 **방장 맡기**를 눌러 이어받습니다. 아무도 누르지 않으면 약 3초 뒤 접속 중인 사람에게 자동 승계합니다. 전 방장이 돌아와도 새 방장 권한을 가져가지 않습니다.
- 설치용 매니페스트와 서비스 워커를 추가했습니다. 게임 화면은 온라인에서 최신 파일을 읽으며 캐시에는 공개된 연결 안내 화면 하나만 보관합니다. 손패·참가 토큰·개인 코드는 푸시나 오프라인 캐시에 넣지 않습니다.
- 운영 서버의 **WEB_PUSH_VAPID** 환경변수가 있어야 푸시를 켤 수 있습니다. 설정 방법은 온라인 배포 안내와 .env.example을 참고하세요. 비밀키는 GitHub에 올리지 않습니다. 키를 바꾸면 기존 기기의 구독을 다시 등록해야 하므로 같은 키를 유지합니다.
- 검증: 기본 검사 70개, 실제 HTTP/SSE의 연결 끊김·기기 변경 복귀·이전 기기 종료·방장 승계, Web Push 암호화와 오류 처리, 실제 서비스 워커·IndexedDB를 사용한 Chrome/WebKit의 한영 설정 화면을 검사합니다. 푸시 공급자 응답과 휴대폰 권한은 모의 처리하며 실제 잠금 화면·스피커 수신은 사용하는 폰의 알림 테스트로 확인해야 합니다. 검사 자료와 비밀키는 qa/에만 두고 배포에서 제외합니다.

공식 참고: [Apple WebKit의 iOS 홈 화면 Web Push 안내](https://webkit.org/blog/13878/), [web-push 라이브러리](https://github.com/web-push-libs/web-push).

## v1.8 · 노란 타일과 원래 자리로 돌아오기 (2026-10-24)

- 갈색으로 보이던 타일을 선명한 **노랑**으로 바꿨습니다. 얇은 어두운 윤곽으로 밝은 도자기 위 숫자를 읽기 쉽게 유지하고, 검정 타일과 구분합니다. 홈 그림, 정렬 버튼, 색 이름, 화면 읽기 안내, 조커 선택과 모든 타일 표시가 같은 색을 사용합니다. 숫자에 흰 그림자를 추가하지 않습니다. 타일 ID와 규칙은 유지합니다.
- 게임 중 **나가기**를 누르면 쉬움 봇이 같은 자리·손패·점수·첫 등록 상태를 이어받습니다. 같은 기기·브라우저에서 **방 코드를 입력하고 참가**하거나 **하던 게임으로 돌아가기**를 누르면 봇이 진행한 현재 상태로 복귀합니다. 닉네임을 다시 입력할 필요는 없습니다.
- 최근 10개 방의 참가 정보를 기기에 보관하므로 다른 방을 방문해도 원래 자리를 기억합니다. 방 코드나 같은 이름만으로 다른 사람의 자리를 가져갈 수는 없습니다. v2.0부터 다른 기기나 저장 정보가 사라진 브라우저에서는 개인 복귀 코드를 사용합니다.
- 모든 사람이 나가도 방과 대타 봇을 **30분 동안** 유지합니다. 돌아오기 전에 판이 끝났다면 결과를 확인합니다. 봇의 진행은 이 보존 시간을 늘리지 않습니다. 서버가 재시작되거나 새로 배포되면 메모리에 있는 방은 사라집니다.
- 한 사람이 여러 탭을 열었어도 나가기를 누르면 모두 홈으로 돌아가며 자동으로 자리를 다시 차지하지 않습니다. 재입장할 때 계산 중이던 봇의 미확정 수를 취소하고, 이미 둔 수와 현재 손패는 보존합니다. 대기실에서 나가거나 강퇴된 참가 정보는 복구용으로 남기지 않습니다.
- 검증: `test.js`, `qa/takeover.cjs`(실제 HTTP/SSE·계산/미리보기 중 복귀·방 보존/만료), `qa/return-ui.cjs`(두 브라우저의 퇴장·봇 진행·다른 방 방문·코드 재입장·한영·보통/큰 타일 화면), `qa/lobby-kick.cjs`(강퇴 회귀). 검사 자료는 `qa/return-v18` 등에 저장하며 배포에서 제외합니다.

## v1.7 · 대기실과 테이블 경험 (2026-10-23)

- 대기실의 내 이름 옆 **수정**으로 닉네임을 바꿉니다. 다른 참가자에게 바로 반영되고, 같은 이름에는 구분 번호를 붙입니다. 게임이 시작되면 이름 변경을 막습니다.
- 폰에서도 보낸 말과 받은 말을 게임판 위 말풍선으로 표시합니다. 대화창을 열어 둔 상태에서도 보이며 이름·아이콘으로 화자를 구분합니다. 100자 원문은 대화창에 보관합니다.
- 상대가 수를 확정하면 공개된 조합을 작은 카드로 보여 줍니다. 금빛 테두리는 이번에 새로 낸 타일이고, 조커의 대체 숫자도 표시합니다. **지난 수**로 현재 접속 중 받은 최근 6개 수를 다시 보고, 새로고침하면 서버에 남은 마지막 수를 확인합니다. 초안·비공개 손패는 카드에 넣지 않습니다. 낮은 가로 화면에서는 자동 카드를 생략하고 버튼으로 엽니다.
- 착지음은 짧은 도자기 접촉·작은 이중 접촉·나무 받침의 울림을 합성했습니다. 실제 착지에 맞춰 재생하며, 숫자 타일에는 글자 그림자를 추가하지 않습니다.
- 직접 구성한 16마디 피아노·마림바 BGM이 첫 화면 조작 후 시작됩니다. 홈·대기실의 음악 버튼 또는 게임 메뉴에서 켜고 끄며, 메뉴에서 효과음과 BGM 음량을 따로 저장합니다. 소리 전체를 끄거나 앱을 배경으로 보내면 BGM도 멈춥니다. 외부 음원 다운로드는 없습니다.
- 검증은 `qa/table-v17.cjs`의 실제 두 참가자 흐름과 7장 조합 확정, Chrome/WebKit의 한영·큰 타일·PC/모바일, 오디오 렌더링으로 확인합니다. 자료는 로컬 `qa/table-v17`에 남기며 배포 파일에서 제외합니다.
- 작혼의 [공식 대국 조작 안내](https://mahjongsoul.com/startguide/assets/jantama_startguide.pdf)를 참고해 화자와 조합의 구분을 우선했습니다. 음악·효과음·카드 디자인은 자체 제작했습니다.

`루미큐브-서버-켜기.cmd` 를 더블 클릭 → 검은 창이 뜨고 브라우저가 열립니다.
**검은 창을 닫으면 서버가 꺼지고 진행 중인 게임도 사라집니다.**

## 친구가 들어오는 방법

| 상황 | 방법 |
|---|---|
| 같은 와이파이(집·교회 등) | 대기실의 **QR 코드를 폰 카메라로 찍기** (가장 쉬움). 또는 **초대 링크 복사**로 보낸 링크, 검은 창에 나오는 `http://192.168.x.x:3000` 주소. 처음에 Windows 방화벽 허용 창이 뜨면 **허용** |
| 멀리 있는 친구(인터넷) | 아래 둘 중 하나 |

- **QR 코드·초대 링크는 자동으로 '같은 와이파이 주소'로 만들어져요.** 이 컴퓨터에서 `localhost`로 열었어도
  친구 폰에서 열리는 `http://192.168.x.x:3000/?r=방코드`가 들어갑니다(서버의 `GET /api/info`가 이 컴퓨터의 와이파이 주소 목록을 알려 줌).
  인터넷 주소(터널·호스팅)로 열었으면 그 주소 그대로 들어갑니다.
- 컴퓨터에 네트워크 어댑터가 여러 개(VirtualBox·Hyper-V 등)면 QR 아래 **다른 주소**를 눌러 바꿔 볼 수 있어요.
- **QR을 누르면 'TV로 보기'** — 큰 방 코드와 큰 QR이 화면 가득. 목장 모임에서 프로젝터·TV에 띄워 두세요. 다시 누르면 닫혀요.
- QR 코드는 브라우저 안에서 직접 그려요(`public/qr.js`, 외부 라이브러리·인터넷 필요 없음). 교회 와이파이가 인터넷에 안 이어져 있어도 됩니다.
- **다시 들어오기**: 같은 기기·브라우저에서 방 코드를 다시 입력하고 참가하면 원래 자리로 돌아와요. 처음 화면의 **▶ 하던 게임으로 돌아가기**로도 복귀합니다. 게임 중 나가면 바로 봇이 대신하고, 연결만 끊긴 경우 45초 기다린 뒤 봇이 맡습니다. 돌아오면 봇이 진행한 현재 손패와 점수를 이어받습니다. 다른 기기나 브라우저에는 참가 정보가 공유되지 않습니다.

### 인터넷으로 열기

1. **임시로 열기 (가장 쉬움)** — Cloudflare Tunnel(`cloudflared`)을 받아서
   서버를 켠 상태로 `cloudflared tunnel --url http://localhost:3000` 실행 →
   나오는 `https://….trycloudflare.com` 주소를 친구에게 보내기. 계정 필요 없음, 컴퓨터가 켜져 있는 동안만 동작.
2. **항상 켜 두기** — Render, Railway, Fly.io 같은 Node 호스팅에 이 폴더를 올리고 시작 명령을 `node server.js`로 지정.
   (포트는 호스팅이 주는 `PORT` 환경변수를 자동으로 씀)

> Netlify는 정적 파일만 올리는 곳이라 이 서버는 돌아가지 않습니다.

## 게임 방법

- 방장이 **새 방 만들기** → 4글자 방 코드나 초대 링크를 친구에게 보냄 → 2명 이상 모이면 **게임 시작**
- 대기실에서 **🤖 쉬움 봇 추가** / **🤖 어려움 봇 추가**로 컴퓨터 상대를 넣습니다(✕로 빼기). 혼자서 봇과 하거나, 친구 + 봇을 섞어 6명까지.
  방장은 봇 옆의 **쉬움/어려움** 표시를 눌러 난이도를 바꿀 수 있어요. 봇은 놓기 전에 1초쯤 놓는 모습을 보여 줍니다.
  - **쉬움**: 한 턴에 묶음 하나만 내고, 조커는 안 쓰고, 테이블에 붙이기도 가끔만 해요. 아이들·처음 하는 분용.
  - **어려움**: 테이블의 모든 묶음을 통째로 다시 짜서 손패를 가장 많이(높은 숫자부터) 내려놓는 방법을 계산해요. 조커는 꼭 필요할 때만 써요.
    시험 대국에서 쉬움 상대로 30판 중 29~30판을 이겼어요.
- **혼자 연습하기**: 쉬운 컴퓨터 1명이 있는 **연습 준비** 대기실로 들어갑니다(기본 시간 제한 없음). 이름을 안 써도 돼요. 쉬움/어려움 봇을 최대 5명까지 넣고, 난이도 변경·삭제 후 **게임 시작**을 누르세요.
- **📖 규칙 한눈에**: 처음 화면 아래, 게임 중 ⋯ 메뉴 맨 위(넓은 화면은 위쪽 **?**). 진짜 타일 그림으로 그룹·런·조커·첫 등록을 보여 줘요.
  처음 하는 분에게는 게임 중에 짧은 안내 말풍선이 기기마다 한 번씩만 떠요(누르면 닫힘, **다시 보지 않기**).
- 손패 타일을 **눌러 고르고**(여러 개 가능) → 테이블의 묶음이나 **새 묶음 만들기**를 누르면 옮겨집니다. 컴퓨터에선 끌어다 놓기도 되고,
  키보드만으로도 할 수 있어요(Tab으로 타일·묶음 이동 → Enter/Space, Ctrl+Z 한 수 되돌리기). 테이블에 놓았던 내 타일은 손패의 **↩** 자리를 눌러 되돌려요.
- 폰을 가로로 들면 테이블이 넓어지도록 타일·위쪽 막대가 조금 작아지고, 안내 말풍선은 떠 있다가 7초 뒤 저절로 닫혀요.
  아이폰처럼 진동이 없는 기기에서는 소리 단추가 **소리 켜짐 ↔ 꺼짐** 두 가지만 바뀌어요.
- 만드는 중인 묶음은 무엇이 모자란지 한 줄로 알려 줘요. 다 맞으면 **완료**, 낼 게 없으면 **뽑기**. **↶ 한 수**는 한 수씩 되돌리기, **처음**은 이번 턴 처음 상태로.
- 첫 등록은 내 타일만으로 30점 이상, 그 전엔 테이블을 못 바꿈.
- 다른 사람 차례에는 그 사람이 타일을 옮기는 모습이 실시간으로 보입니다.
- **채팅**: 대기실에선 카드 아래 대화 상자, 게임 중엔 위쪽 💬 버튼(안 읽은 수 표시)으로 엽니다. 창을 닫아 둬도 새 메시지가 잠깐 말풍선으로 떠요.
  자주 쓰는 말(아멘 🙏, 👍 좋아요, 할렐루야 🙌 …)은 한 번 눌러 보내기. 봇도 인사하고 좋은 수에 박수를 쳐 줘요. 한 메시지 100자, 도배 방지(10초에 5개).
- **⋯ 메뉴 → 내 화면 설정** (이 기기에만 저장, 다른 사람 화면은 그대로)
  - **색 구분 기호**(기본 켬): 빨강 ● 파랑 ▲ 노랑 ■ 검정 ◆ 작은 모양을 타일 왼쪽 위에 표시해 색 이외에도 모양으로 구분합니다.
  - **큰 타일**: 타일과 글씨를 약 1.25배로 (어르신·작은 폰).
  - **효과 줄이기**: 움직이는 효과를 끔(색과 소리는 그대로). 폰에서 '동작 줄이기'를 켜 두었으면 처음부터 켜져 있어요.
  - **조커 모양**: 십자가(기본) / 별 / 비둘기 — 진짜 타일 미리보기 중에서 고름. 그림 문자 대신 그림(SVG)이라 어느 폰에서나 똑같이 보여요. v1.4.1 업데이트 후에는 기존 기기도 십자가로 시작하고, 이후 선택은 기기에 저장합니다.
    내 화면에만 적용되고 서버로 보내지 않아요. 글에서는 늘 '조커'라고 부르고, 감점은 '조커 −30'으로만 적어요.
- **오늘의 시상식**: 판이 끝나면 점수가 올라가며 보이고, 이어서 한 사람에 하나씩 상아색 카드에 상이 켜져요
  (승리 · 재건축왕 · 한 방의 손 · 첫 열매 · 조커의 달인 · 부활의 손 · 끈기상 · 함께해서 기뻐요). 상은 점수와 상관없는 명예상이에요.
  카드를 누르면 기다리지 않고 한 번에 다 보여요. 아래에 시편 133:1과 '오늘 n판' 누적 점수·★(이긴 판)가 나와요.
- **📋 결과 공유**: 폰에서는 공유 창(카카오톡 단톡방 등)이, 컴퓨터에서는 복사가 돼요. 6줄 이하 · 주소와 손패는 넣지 않아요.
- 방장은 대기실에서 턴 제한 시간(없음/60초~3분)을 정할 수 있어요. 시간이 지나면 자동으로 1장 뽑고 넘어갑니다.
- 게임 중 **나가기**를 누르면 쉬운 대타 봇이 내 타일·점수·첫 등록 상태·자리를 그대로 이어받습니다. 연결이 잠깐 끊겼을 때는 차례나 턴 타이머에 관계없이 45초 기다린 뒤 봇이 맡습니다. 두 경우 모두 같은 기기·브라우저에 저장된 참가 정보와 방 코드로 직접 플레이에 복귀할 수 있습니다.
- 누가 손패를 다 내면 승리. 진 사람은 남은 타일 합(조커 30)만큼 감점, 승자는 그만큼 가산. 더미가 떨어지고 모두 패스하면 남은 합이 가장 적은 사람이 승리.

## 컴퓨터 상대 자유롭게 구성하기 (v1.2.0)

- **연습 준비**: 쉬운 봇 1명을 기본으로 넣고 기다립니다. 바로 시작하지 않습니다. 1~5명의 봇을 쉬움/어려움으로 섞고, 각 봇의 난이도 표시를 눌러 바꾸거나 ✕로 뺀 뒤 시작합니다.
- **친구와 하기 · 방 만들기**: 방장이 친구와 봇을 섞어 최대 6명으로 구성합니다. 친구는 봇 구성과 난이도 변경을 실시간으로 봅니다.
- 빈자리 수, 가득 찬 상태, 방장 권한을 안내합니다. 상대 설정 요청이 진행되는 동안 추가·삭제·난이도·시작 요청이 겹치지 않게 막습니다.

- 본인이 뽑은 타일은 상단 더미에서 손패로 390ms 동안 들어와 안착하며, 나무 받침에 닿는 낮은 소리가 납니다. 서버의 실제 지급 상태를 받은 뒤에만 시작합니다. HTTP 응답이 먼저 오거나 나중에 와도 연출을 중복하지 않고, 응답 완료가 이미 시작한 이동을 끊지 않습니다. 패스와 실패한 요청에는 뽑기 소리가 없습니다.
- 손패가 길어 새 타일이 가려졌다면 그 자리로 스크롤해 보여 줍니다. 효과 줄이기에서는 이동을 생략하고 접촉음을 바로 냅니다. 다음 조작·스크롤·화면 회전·탭 숨김에서 복사본과 대기 중인 접촉음을 취소하고 실제 타일을 복원합니다. 초기 입장·새로고침·언어 전환에는 뽑기 효과를 반복하지 않습니다.
- 선택·정렬·뽑기·착지 소리를 마찰음과 낮은 접촉음 중심으로 조정했습니다. 조합 완성·첫 등록·승리의 화음, 음량 설정, 무음·진동 지원은 유지합니다. 소리는 외부 파일 없이 WebAudio로 만듭니다.
- 작은 폰의 6인 자리표와 더미·채팅·메뉴가 겹치지 않게 헤더를 조정했습니다. 높이 360px 이하의 짧은 가로 화면은 받침을 한 줄 높이의 스크롤 영역으로 줄여 게임판과 완료 버튼을 확보합니다. 모바일 터치, 키보드, 큰 타일, 한국어/영어, 기본 106개·확장 160개 게임 구성은 유지합니다.
- 검사 스크립트: `qa/atelier-draw.cjs`는 실제 서버/UI/SSE로 뽑기 응답 순서·단일 소리·타일 보존·취소·큰 손패·패스·실패·새로고침을 검사합니다. `qa/atelier-layout.cjs`는 긴 이름의 6인 자리표·타이머·큰 타일·짧은 가로 화면·고대비 모드를 확인합니다. `qa/modern.cjs --atelier`와 `qa/feel-preview.cjs --atelier`는 새 화면과 실제 합법 수의 미리보기를 로컬 `qa/atelier`에 저장합니다. QA 파일은 배포용 폴더에 포함하지 않습니다.
- 검증 결과: 기본 검사 69개, 전체 화면 16개 조합, UX 28개 조합, 6인 레이아웃 40개 조합(각각 선택 상태도 확인), 타일 전수 검사 20개 조합, 실제 뽑기 4개 조합, 착지·완성·음량 8개 조합이 통과했습니다. Chrome/WebKit에서 실제 6인 서버의 뽑기·7장 놓기·조커 확정·160개 타일 보존도 확인했습니다. 새 마찰·접촉음을 포함한 10개 음량/소리 샘플을 오프라인 렌더링해 무음·음량 변화·클리핑을 검사했습니다.
- Chrome/WebKit 브라우저 에뮬레이션으로 검사합니다. 실물 휴대폰의 가상 키보드·노치·스피커 음색·진동 감각은 별도 확인이 필요합니다.
- 참고: [작혼 공식 조작 안내](https://mahjongsoul.com/startguide/assets/jantama_startguide.pdf), [Tetris Effect 작곡가의 사운드 제작 이야기](https://blog.playstation.com/2020/05/28/inside-the-creation-of-tetris-effects-original-soundtrack-out-today/). 타일을 집어 옮기는 흐름과 움직임·소리를 함께 조율하는 원리를 참고했습니다. 그림·질감·소리·효과는 자체 제작했습니다.

## 5~6인 확장판과 손맛 (v1.2.0)

- 2~4명은 기존 106개(숫자 2벌·조커 2개), 5~6명은 160개(숫자 3벌·조커 4개)를 사용합니다. 시작 손패는 항상 14개입니다. 공식 Piatnik 2~6인 확장 규칙에 맞춘 구성입니다: https://www.piatnik.com/uploads/media/default/0001/03/5a8e17ffb90ef476618fa071af4a25ae898b432f.pdf
- 인원에 따른 타일 구성을 대기실에서 안내합니다. 다음 판 시작 시 현재 인원으로 다시 정합니다. 진행 중 누군가 나가도 그 판의 타일 구성은 유지합니다.
- 기존 타일 ID 0~105를 보존하고 106~157에 세 번째 숫자 벌, 158~159에 추가 조커를 배치합니다. 규칙·벌점·봇·효과는 공통 `tile(id)`로 판독합니다.
- 확장판 어려움 봇은 일부 유효한 묶음을 보존한 채 기존 DP 한도 안에서 재배치하고, 전체 손패를 쓰는 기본 전략과 비교합니다. 전역 최적해를 보장하는 탐색은 아닙니다. 서버 규칙 검증 후에만 수를 적용합니다.
- 5~6명의 자리표는 PC에서 3열, 좁은 폰에서 2열로 정리합니다. 타일 크기는 인원 때문에 줄이지 않습니다.
- 손패에서 테이블로 이동하는 타일은 작은 착지 반동과 짧고 조용한 접촉음으로 마무리합니다. 종료 이벤트가 늦어져도 타일 복원과 소리를 함께 완료하며, 중간 취소에는 접촉음을 남기지 않습니다.
- 묶음 확정음은 짧은 접촉음 뒤에 화음을 겹칩니다. 최대 음성 수·반복 재생 제한·소리 끄기 설정을 따릅니다. 효과 줄이기에서는 타일 이동과 지연 착지음을 생략합니다.
- 추가 검증: 확장판 봇 12판의 합법 수·타일 보존·종료, 실제 서버의 5~6명 분배·차례 순환, 사람+봇 5명의 경기 종료·6인 결과·시상·방 정리. `qa/motion.cjs`는 착지·취소·효과 줄이기를 검사합니다.
- 조사와 다음 개발 우선순위는 프로젝트의 `GOTY-개선검토.html`에 정리했습니다.

## 어떤 기기에서 되나요

컴퓨터(크롬·엣지, 마우스 끌어다 놓기·키보드), 태블릿, 안드로이드 폰, 아이폰(사파리) 모두 — 세로·가로 둘 다 됩니다.
폰 가로 화면에선 테이블이 넓어지도록 위쪽 막대·타일이 조금 작아지고, 넓은 화면에선 채팅이 오른쪽 창으로 떠요.
(아이폰은 진동이 없어 소리 단추가 '켜짐 ↔ 꺼짐' 두 가지만 바뀌어요.)

## 파일

- `server.js` — 서버 (방, 차례, 규칙 최종 판정, 실시간 전송). 손패는 본인에게만 보내므로 개발자도구로 남의 패를 볼 수 없음
- `bot.js` — 컴퓨터 상대의 수 계산 (쉬움 / 어려움). `bot-worker.js`가 별도 스레드에서 돌려서 봇이 생각하는 동안에도 서버가 멈추지 않음
- `public/rules.js` — 규칙 판정 (서버와 브라우저가 같이 씀)
- `public/index.html`, `app.js`, `style.css` — 화면
- `public/modern.css` — 화면 배치와 디자인의 기본 구조
- `public/atelier.css`, `felt-weave.svg`, `wood-grain.svg`, `table-scene.svg`, `brand.svg` — v1.5 도자기·펠트·월넛 테이블과 로컬 벡터 그림
- `public/table-feel.css`, `table-feel.js`, `tile-grain.svg` — v1.4 타일 재질·착지·완성 효과와 음량 조절 UI
- `public/flow.js`, `flow.css` — 대기실 QR·TV로 보기, 오늘의 시상식·결과 공유, 규칙 한눈에, 처음 안내, 혼자 연습, 내 화면 설정 모양
- `public/i18n.js` — 한국어·영어 사전과 말 바꾸기
- `public/sfx.js` — 소리·진동 (파일 없이 브라우저에서 직접 만든 종소리, 한 음계라 겹쳐도 어울림)
- `public/qr.js` — QR 코드 그리기 (외부 라이브러리 없이, 오류 정정 M, 버전 1~10)
- 서버가 보내는 상태에는 판마다의 기록(`awards` 시상식, `history` 오늘 판 기록)과 사람마다 `offFor`(연결 끊긴 초)·`graceLeft`(자동 진행까지 남은 초)가 들어 있어요
- `test.js` — 테스트: `node test.js`

## UX 정교화 (2026-10-10)
- 선택 상태를 손패 위에 표시: 선택 개수, 새 묶음에 놓기, 손패로 돌리기, 선택 해제. Esc로도 선택 해제.
- 4명 참가자 이름표는 좁은 폰에서 2열로 배치. 긴 이름은 말줄임하고 타일 수는 유지.
- 손패 높이를 제한하고 내부 스크롤 적용. 손패·테이블·긴 묶음의 스크롤 위치는 타일 선택·언어 전환 후에도 보존.
- 연결 중/재연결/오프라인을 구분해 안내. 연결이 불안정하면 서버 확정 버튼을 막고 로컬 작업은 보존(실제 차례가 바뀌면 서버 상태를 따름).
- 전송 중 중복 뽑기·완료 요청 방지, 제출한 타일 배열 복사, 네트워크 요청 12초 제한과 번역된 오류 메시지.
- 채팅 중복 제출 방지. 전송 중 다음 메시지를 작성했다면 새 문장을 지우지 않음.
- PC 키보드: 방향키로 타일 이동, Home/End로 처음·끝, Enter/Space로 선택. 새 묶음에 놓은 뒤 초점이 타일을 따라감.
- 정렬 단추는 실제 정렬 상태를 표시. 규칙·결과 창의 Tab 초점이 뒤쪽 화면으로 빠지지 않음.
- 검사: 기존 62개 통과. Chrome·WebKit 각각 7개 화면×한국어/영어(총 28개 조합), 손패 40개·4명·긴 묶음·큰 타일·연결 상태·중복 제출·채팅 초안 검사.

- 실물 Galaxy/iPhone, 실제 운영 서버의 인터넷 지연, 운영체제 가상 키보드는 별도 확인 필요.
